# Education & Skills Passport Core — Contract Error Codes

Every failure mode from the `contracts/passport` Soroban contract (`SkillsPassportContract`) maps to a defined `PassportError` numeric discriminant in [`src/types.rs`](src/types.rs).

| Code | Variant | Raised by | Trigger Condition | Suggested Next Action |
| ---: | --- | --- | --- | --- |
| 1 | `NotInitialized` | `get_admin`, `register_issuer`, state mutators | Contract `Admin` instance key is not initialized yet. | Call `initialize(admin)` before invoking administrative or issuance functions. |
| 2 | `AlreadyInitialized` | `initialize` | `initialize` called on an already-initialized contract. | Do not re-initialize; query `get_admin()` to inspect the active administrator. |
| 3 | `Unauthorized` | `revoke_credential`, `suspend_credential`, `reactivate_credential`, `issue_credential`, `batch_issue_credentials` | Caller is neither contract admin nor the authorized owning issuer (or attempted to use another issuer's registered template). | Sign with the issuing institution's key or the contract administrator key. |
| 4 | `IssuerNotAuthorized` | `register_template`, `issue_credential`, `batch_issue_credentials`, `update_issuer_metadata`, lifecycle mutators | Issuer is unregistered or has been deauthorized (`is_active == false`). | Verify issuer status via `is_issuer_authorized(issuer)`; request admin reactivation or rotate to a new issuer key. |
| 5 | `CredentialAlreadyExists` | `issue_credential`, `batch_issue_credentials` | A record with the same 32-byte `credential_id` already exists (or appears twice in a batch). | Generate a fresh unique `credential_id` (UUID v4 / SHA-256) and avoid replaying prior issuance IDs. |
| 6 | `CredentialNotFound` | `revoke_credential`, `suspend_credential`, `reactivate_credential`, `get_credential_status`, `verify_credential` | No `Credential(credential_id)` record exists in persistent storage. | Confirm the 64-character hex `credential_id` and target contract ID. |
| 7 | `CredentialAlreadyRevoked` | `revoke_credential`, `suspend_credential` | Credential status is already `CredentialStatus::Revoked`. | Revocation is permanent and irreversible; issue a new credential if a corrected record is needed. |
| 8 | `CredentialNotSuspended` | `reactivate_credential` | Credential status is `Active` or `Revoked` (not `Suspended`). | Only `Suspended` credentials may be reactivated. Revoked credentials cannot be restored. |
| 9 | `InvalidExpiration` | `issue_credential`, `batch_issue_credentials`, `reactivate_credential` | Supplied `expires_at` timestamp is `<=` current ledger timestamp, or credential is already expired at reactivation. | Supply a future Unix timestamp (`expires_at > now`), or issue a new credential with a valid validity window. |
| 10 | `IssuerAlreadyRegistered` | `register_issuer`, `rotate_issuer_key` | Target issuer address is already present in persistent storage. | Use `reactivate_issuer` or `update_issuer_metadata` instead of re-registering. |
| 11 | `IssuerNotFound` | `update_issuer_metadata`, `deauthorize_issuer`, `reactivate_issuer`, `rotate_issuer_key` | Target issuer address is not registered on-chain. | Register the institution first with `register_issuer`. |
| 12 | `TemplateAlreadyExists` | `register_template` | A template with the same `template_id` Symbol already exists. | Choose a distinct `template_id` Symbol. |
| 13 | `TemplateNotFound` | (reserved) | Reserved for strict template lookup workflows. | Register the template first with `register_template`. |
| 14 | `InvalidInput` | `issue_credential`, `batch_issue_credentials`, `register_issuer`, `update_issuer_metadata`, `register_template`, `revoke_credential`, `suspend_credential`, `set_admin`, `propose_admin`, `rotate_issuer_key`, `get_learner_credentials_page` | All-zero `credential_id` or `credential_hash`, self-issuance (`issuer == recipient`), empty/oversized string, empty batch, self-admin/self-rotation, or out-of-range pagination limit (`0` or `> 100`). | Validate inputs client-side using `EducationPassportClient` before submitting transactions. |
| 15 | `BatchTooLarge` | `batch_issue_credentials` | Batch contains more than `MAX_BATCH_SIZE` (50) items. | Split batch issuance into chunks of at most 50 credentials per transaction. |
| 16 | `CredentialAlreadySuspended` | `suspend_credential` | Credential is already in `CredentialStatus::Suspended` state. | No action needed unless revoking permanently (`revoke_credential`) or restoring (`reactivate_credential`). |
| 17 | `ContractPaused` | `register_issuer`, `update_issuer_metadata`, `reactivate_issuer`, `register_template`, `issue_credential`, `batch_issue_credentials`, `reactivate_credential` | Emergency pause circuit breaker is active (`is_paused() == true`). | Wait for administrator `unpause()`. Note: `verify_credential`, `deauthorize_issuer`, `revoke_credential`, and `suspend_credential` remain active during pause. |
| 18 | `NoPendingAdmin` | `accept_admin` | No pending admin transfer has been proposed via `propose_admin`. | Current administrator must call `propose_admin(new_admin)` before `accept_admin()`. |
| 19 | `IssuerAlreadyDeauthorized` | `deauthorize_issuer` | Issuer is already inactive (`is_active == false`). | No further action required; credential verification already treats issuer as deauthorized. |
| 20 | `IssuerAlreadyActive` | `reactivate_issuer` | Issuer is already active (`is_active == true`). | No further action required. |
